# Member Fund Webapp

A web application that lets Australian superannuation members look up their fund's APRA annual performance test status — Pass, Fail, or Unknown — without navigating APRA's Excel-based website.

Data Extracted through https://github.com/alpeshweta/Member-Performance-Data-Extraction

**Live features:** MySuper fund search, TDP (Choice) fund search, performance dashboard with history and risk signal.

---

## What it does

| Page | Purpose |
|------|---------|
| Page 1 (`/#/`) | Search and select your MySuper or Choice (TDP) fund by name |
| Page 2 (`/#/fund/:id`, `/#/fund/tdp/:id`) | View Pass/Fail badge, supporting metrics (NIR, fees), year-by-year history, and a computed risk signal |
| Page 3 | Compare funds — planned (Capability 5) |

The risk signal on Page 2 tells members whether their fund is **Clear**, **At Risk**, **Critical** (consecutive fails), **Unknown**, or has **Insufficient data** — computed at runtime from the history object, not pre-stored.

|---------|--------|
| Framework | React 18 |
| Build tool | Vite 6 |
| Language | TypeScript 5 (strict mode) |

Static site — no backend, no API, no database.

---

## Data source

Performance data is served from `public/performance-data.json`, generated by the APRA data pipeline from APRA's CPPP Excel files.

- **127 MySuper products**, **1,706 TDP options**
- Updated annually after APRA releases results (typically June)
- To refresh: re-run the APRA pipeline → copy updated `performance-data.json` → commit → redeploy

## Key design decisions

- **Client-side only** — all search and computation runs in the browser; `performance-data.json` is the sole data source
- **HashRouter** — avoids 404s on static hosting without server-side redirect config; URLs are `/#/fund/...`
- **ARIA 1.2 combobox pattern** — `role="combobox"` on input, `role="listbox"` on dropdown, `role="option"` on each item, `aria-activedescendant` for keyboard navigation
- **RAG colours reserved for Page 2** — green/amber/red are not used on the search page
- **Risk signal computed at runtime** — not pre-stored; uses the two most recent years from the `history` object sorted descending; `"Unknown"` does not count as `"Fail"`
